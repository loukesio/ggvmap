# ggvmap: Voronoi Map Treemaps for ggplot2

Compute and visualise Voronoi map treemaps – space-filling partitions of
convex polygons where each cell's area is proportional to an underlying
weight. The algorithm iteratively adapts site positions and
power-diagram weights until convergence, following the approach of Nocaj
and Brandes (2012)
[doi:10.1111/j.1467-8659.2012.03078.x](https://doi.org/10.1111/j.1467-8659.2012.03078.x)
. Supports hierarchical (grouped) layouts, a decorative outer annotation
ring, and flag / image / value annotations. Pure R implementation with
no compiled-code dependencies and first-class ggplot2 integration.
